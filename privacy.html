PRIVACY POLICY

นโยบายความเป็นส่วนตัวของ n8n-auto

หน้านี้อธิบายการจัดการข้อมูลในเวิร์กโฟลว์ของแอป n8n-auto

ข้อมูลที่ใช้ / Data used

แอปอ่านทะเบียนลูกค้าและการจับคู่ข้อมูลจาก Google Sheets ที่กำหนด และอ่านข้อมูลผลการโฆษณาจาก Meta ในโหมดอ่านอย่างเดียว ข้อมูลเหล่านี้ใช้เพื่อจัดเตรียมข้อมูลดิบรายวันและข้อมูลสื่อปัจจุบันแยกตามลูกค้า พร้อมผลการซิงก์และการตรวจสอบคุณภาพข้อมูล

วัตถุประสงค์และการจัดเก็บ / Purpose and storage

แอปใช้ข้อมูลเพื่อซิงก์และตรวจสอบข้อมูลการดำเนินงาน โดยเขียนผลลงใน Google Sheets ที่ผู้ดูแลกำหนด เวิร์กโฟลว์เก็บข้อมูลสำรองและประวัติการทำงานเพื่อช่วยในการกู้คืน การจัดเก็บข้อมูลการดำเนินงาน ข้อมูลสำรอง และประวัติอยู่ภายใต้การตั้งค่าและการดูแลของผู้ดูแล

การอนุญาตและผู้ให้บริการ / Authorization and providers

ผู้ดูแลควบคุมการอนุญาตและสิทธิ์เข้าถึงข้อมูล การเชื่อมต่อ Google Sheets ใช้ Google OAuth ตามการอนุญาตของเจ้าของบัญชี Google Sheets และผู้ให้บริการโฮสติ้งประมวลผลข้อมูลเพื่อรองรับการทำงานและการจัดเก็บที่เกี่ยวข้อง

คำถามเกี่ยวกับข้อมูล / Data requests

หากต้องการสอบถามเกี่ยวกับการเข้าถึงข้อมูล การเพิกถอนสิทธิ์ หรือการลบข้อมูล รวมถึงข้อมูลสำรองและประวัติ โปรดติดต่อผู้ดูแลที่ chalermratvirunya@gmail.com เพื่อพิจารณาคำขอตามข้อมูลและการตั้งค่าของเวิร์กโฟลว์ที่เกี่ยวข้อง

เว็บไซต์นี้ / This website

เว็บไซต์นี้เป็นหน้าให้ข้อมูลเกี่ยวกับแอป ไม่มีแบบฟอร์ม ตัวติดตาม เครื่องมือวิเคราะห์ หรือแดชบอร์ดข้อมูลลูกค้า การให้บริการหน้าเว็บไซต์ใช้ GitHub Pages
